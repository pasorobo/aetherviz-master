Ch.10 RRT\* / 漸近最適計画 Asymptotic Optimality via Rewiring

学習目標

  • □ RRT との違い：近傍探索 + コスト最適化を理解
  • □ ノードのコスト（root からの累積距離）を追跡
  • □ リワイヤリング（rewiring）操作を観察
  • □ 反復回数増 → パス品質向上を確認

RRT\* 主要ステップ

1. q_rand ← sample 2. q_near ← nearest(q_rand) 3. q_new ← steer(q_near, q_rand, ε) 4. if collision_free: 5. N ← neighbors(q_new, r) 6. choose_parent: 最小コスト親 7. add q_new to T 8. rewire: 近傍ノードの親を q_new に張替えてコスト改善

近傍半径

$$ r(n) = \min(\gamma_{\mathrm{rrt*}} \left(\frac{\log n}{n}\right)^{1/d}, \varepsilon) $$

理論的には n→∞ で漸近最適。実装簡略化のため固定半径を使用可。
