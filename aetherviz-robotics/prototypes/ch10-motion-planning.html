Ch.10 Motion Planning (RRT) / 運動計画 Sampling-Based Planner

学習目標

  • □ コンフィギュレーション空間 C と障害物 C_obs を理解する
  • □ サンプリングベース計画 (RRT) のアルゴリズムを追う
  • □ 確率的完全性 (probabilistic completeness) を実感する

RRT アルゴリズム

T = {q_start} while iter < max: q_rand ← sample() (with prob p_goal: q_rand=q_goal) q_near ← nearest(T, q_rand) q_new ← steer(q_near, q_rand, ε) if collision_free(q_near, q_new): add q_new to T (parent: q_near) if dist(q_new, q_goal) < tol: return path(q_new)

使い方

モードを選択し、キャンバス上をクリック。
1. start 設定
2. goal 設定
3. obstacle：左ドラッグで矩形配置
4. 「計画」で RRT 実行
